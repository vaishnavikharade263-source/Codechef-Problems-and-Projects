Currently there are courses for 4 languages, and hence there are 8 courses in this section. But suppose there are courses for NNN languages, what will be the total number of courses in this section?

Input Format
The only line of input will contain a single integer NNN, denoting the number of languages for which there are courses.

Output Format
Output on a single line the total number of courses in the section.

Constraints


1≤N≤1001 \leq N \leq 1001≤N≤100


Sample 1:
InputOutput4
8

Explanation:

If there are 444 languages, then there will be 2∗4=82 * 4 = 82∗4=8 courses in total.

Sample 2:
InputOutput9
18

Explanation:

If there are 999 languages, then there will be 2∗9=182 * 9 = 182∗9=18 courses in total.</a></h2>
